Cippotto — CHIP-8 emulator demo

This page runs the cippotto CHIP-8 emulator directly in your browser, compiled to WebAssembly.
Pick a ROM, optionally enable quirk flags, then press Run to start.

Quirks

Controls

The original CHIP-8 keypad is mapped to the left side of a QWERTY keyboard:

CHIP-8          Keyboard
1 2 3 C         1 2 3 4
4 5 6 D   -->   Q W E R
7 8 9 E         A S D F
A 0 B F         Z X C V

Quirks

CHIP-8 has a handful of instructions whose exact behavior was ambiguous or diverged between the original COSMAC VIP interpreter and later ones (like SUPER-CHIP). This emulator defaults to the modern/common behavior, and lets you opt into the legacy behavior per-flag:

FlagAffectsBehavior when enabled
--quirk-shift-vy 8XY6 / 8XYE (shift) Shifts VY instead of VX and stores the result in VX
--quirk-wrap DXYN (draw sprite) Sprites wrap around screen edges instead of being clipped
--quirk-jump-vx BNNN (jump with offset) Uses VX as the offset register, i.e. BXNN behavior
--quirk-fx55-increment FX55 / FX65 (memory load/store) Increments the I register as it reads/writes registers to memory
